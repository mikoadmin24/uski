## 2. ARSITEKTUR DOMAIN GANDA & STRATEGI KANONIKAL

USKI STORE saat ini memiliki dua aset alamat web aktif:
1. **`https://uskistore.com`**: Ditargetkan sebagai **Domain Kanonikal Tunggal (Primary Canonical Domain)**. Domain `.com` memiliki kredibilitas global, bobot *backlink equity* tertinggi, serta konsisten dengan konfigurasi OpenGraph dan manifest sistem produksi.
2. **`https://uskistore.jat.web.id`**: Domain regional Indonesia yang digunakan dalam masa pengembangan atau penamaan regional Jateng (`.jat`).

### Aturan Eksekusi Kanonikal (Canonical Directives):
- **Server-Level 301 Permanent Redirect (Rekomendasi Utama)**: Pada router Cloudflare / Vercel / Nginx, seluruh permintaan HTTP dari `https://uskistore.jat.web.id/*` dialihkan permanen (HTTP 301) ke `https://uskistore.com/*`.
- **HTML Canonical Fallback Tag**: Jika kedua domain tetap melayani konten selama periode transisi, seluruh halaman pada `uskistore.jat.web.id` wajib menyematkan tag kanonikal absolut yang mengarah ke `uskistore.com`:
  ```html
  <link rel="canonical" href="https://uskistore.com/products/kitab-fathul-qorib-syarah-taqrib" />
  ```
- **Robots.txt & Sitemap Indexing**: File `robots.txt` dan `sitemap.xml` secara tegas hanya merujuk pada alamat induk `https://uskistore.com` guna mencegah pembagian otoritas domain (*domain equity dilution*) dan menghindari penalti duplikasi konten Google.

### 5.2 Formula Gramatikal & Generator Kata Kunci Long-Tail

Untuk memenangkan persaingan tanpa harus bertarung langsung dengan raksasa marketplace nasional (Shopee/Tokopedia) pada kata kunci berkepala pendek (*head keywords*), USKI STORE memanfaatkan formula modifikasi struktural bahasa Indonesia dan tradisi pesantren:

$$\text{Query}_{\text{Long-Tail}} = [\text{Kata Kerja Transaksi}] + [\text{Entitas Produk}] + [\text{Spesifikasi / Varian}] + [\text{Penerbit / Brand}] + [\text{Modifikator Geografis}]$$

#### Formula 1: Kitab Kuning Pesantren
$$\{\text{beli} \mid \text{harga} \mid \text{jual}\} + \{\text{kitab}\} + [\text{Nama Kitab}] + \{\text{makna petuk} \mid \text{makna jawa pegon} \mid \text{kosongan}\} + \{\text{kertas kuning} \mid \text{putih}\} + \{\text{kesugihan} \mid \text{cilacap} \mid \text{al ihya}\}$$
*Contoh Realistis*: `beli kitab fathul qorib makna petuk kertas kuning kesugihan cilacap`

#### Formula 2: Mushaf Al-Qur'an Pesantren
$$\{\text{jual} \mid \text{toko}\} + \{\text{mushaf} \mid \text{al quran}\} + [\text{Menara Kudus} \mid \text{Tikrar} \mid \text{Al-Bayan}] + \{\text{pojok 15 baris} \mid \text{tajwid warna}\} + \{\text{a5} \mid \text{besar}\} + \{\text{cilacap} \mid \text{banyumas}\}$$
*Contoh Realistis*: `jual mushaf menara kudus pojok 15 baris asli cilacap banyumas`

#### Formula 3: Buku Kurikulum & Pelajaran
$$\{\text{buku paket} \mid \text{buku teks}\} + [\text{Mata Pelajaran}] + [\text{Jenjang: SD/SMP/SMA/MTs/MA}] + \{\text{kurikulum merdeka} \mid \text{kemenag kma 183}\} + [\text{Kelas 1-12}] + \{\text{cilacap}\}$$

#### Formula 4: ATK & Perlengkapan Grosir / B2B
$$\{\text{pengadaan} \mid \text{distributor} \mid \text{grosir}\} + [\text{kertas hvs} \mid \text{buku tulis} \mid \text{map ijazah raport}] + \{\text{sekolah} \mid \text{kantor desa} \mid \text{dana bos}\} + \{\text{kesugihan} \mid \text{cilacap}\}$$
